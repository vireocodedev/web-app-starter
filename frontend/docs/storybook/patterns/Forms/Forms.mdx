## 2. Adapt the contract to a real feature

Keep domain rules, validation and state with their feature owner. These panels explain one mechanism at a time; the corresponding focused tutorials provide complete feature-level recipes. Copy only the responsibility you need and wire its real dependencies explicitly. Never import this documentation tree from production source.

## 3. Verify behavior and cleanup

The migrated checks under `tests/storybook/patterns/` retain model, API, form, query, routing and gallery behavior coverage. Exercise failure, retry, cancellation and narrow-screen states relevant to your feature. These previews do not prove backend authority or database durability.
