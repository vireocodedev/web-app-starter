# Consumer initialization contract

The authoritative reusable contract ships inside the
[initialize-project skill](../.agents/skills/initialize-project/references/contract.md).
It owns preparation, current written authority, readiness, resume and acceptance.

Before a fresh invocation, use the
[preparation guide](../.agents/skills/initialize-project/references/preparation.md)
to save the private workbook. See the
[setup runbook](template-initialization.md) for the procedure and consumer-specific
setup decisions. Existing completed consumers retain their evidence; a new form
does not authorize reinitialization.
